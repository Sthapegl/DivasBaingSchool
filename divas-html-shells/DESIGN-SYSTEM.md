# Design system
**Reference:** the Festive Specials homepage design (rose/pink primary, orange accent, light-brown text, Georgia headings, 6px buttons, 10px cards, flat footer). See limitations in TEST-REPORT.md about what could be inspected.
**Files:** `assets/css/divas-design-system.css` (shared tokens + components, 20 labelled sections), `assets/css/divas-pages.css` (page-specific rules only), `assets/js/divas-ui.js`.
**Tokens (`:root`):** ink `#3b2418`, paper `#fff6f0`, surface `#fdebe0`, border `#f0dcd0`, muted `#7a5f52`, accent `#b3245e`, accent-light `#d9467f`, accent-dark `#8f1b4a`, gold `#f39a4a`, warm `#f27d2e`, success `#276749`, error `#b42318`, footer `#5e3524`. Type: Georgia headings, "Segoe UI"/system-ui body; scale `--dbs-text-sm … -3xl`. Spacing `--dbs-space-1…16`. Radii 6px / 10px / pill. Focus ring: 3px gold.
**Layout:** container 72.5rem, reading width 46rem. Breakpoints: 30rem (phone), 40rem (tables stack), 48rem (two-column splits), 53.75rem (header collapses to Menu), 56rem (account/cart/checkout sidebars).
**Components:** utility bar, sticky header + cart count + mobile Menu, gradient page band with breadcrumbs, footer (3 columns), buttons (primary, gold, secondary, text, small, disabled), form fields/password/choice/fieldset/validation, panels/cards, badges, alerts (dismissible), accordion, tabs, dialog, account layout/nav, cart item + stepper + summary, tables (stack to labelled blocks under 40rem), empty/loading/skeleton states, state gallery.
**Scoping:** every class `dbs-` prefixed; element selectors only under `.dbs-page-root` (use a wrapper `<div class="dbs-page-root">` inside WordPress). No `!important` (one `.dbs-page-root [hidden]` rule protects the hidden attribute from component display rules). Only the page band uses a gradient, matching the homepage hero.
**JS (`divas-ui.js`, ~7.5 KB unminified, no dependencies):** mobile nav toggle (Esc closes), password show/hide, password-match feedback, dismissible notices, FAQ expand/collapse all + search, tabs (arrow/Home/End keys), form validation with field-level messages (preview: nothing is sent), cart quantity stepper / sample subtotal / remove-with-dialog / empty state, checkout "ship to different address" toggle, footer year. Without JS everything is readable: nav wraps, tab panels stack, cart items show.
